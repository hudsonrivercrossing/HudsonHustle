# 河南底图提示词（备用）

当前的河南底图是 `scripts/config/henan-basemap.mjs` 用程序画的。如果想换成 AI 绘制的手绘版，可以用下面的提示词，并把 `node scripts/config/henan-basemap.mjs --preview henan-reference.png` 生成的图作为参考图一起给模型，要求它保持河道、省界和站点的位置不变。生成后导出为 1600×1200 的 `.webp`，放到 `apps/web/public/basemaps/`，再改 `configs/hudson-hustle/releases/henan/visuals.json` 里的 `backdrop.image.href`。

## 提示词

> 一张中国河南省的手绘复古地图，4:3 横幅，俯视平面图，做旧羊皮纸底色，淡墨线条加水彩淡染，和二十世纪初的铁路旅行地图同一种气质。
>
> 构图严格按参考图：省界轮廓、黄河河道、各圆点（车站）的位置都不能移动。
>
> 要画的内容：
> - 黄河：自西向东横贯图的中上部，在右侧折向东北流出；灰青色水面，两岸有浅黄色滩地。
> - 淮河：图的下方自西向东的一条细河。
> - 太行山：左上方沿西北省界的一带山峰，用小山形符号加橄榄绿淡染。
> - 伏牛山：左下方的大片山地；嵩山：中部偏左的一小组山峰；桐柏山和大别山：沿下方省界。
> - 东部和中部是平原，只画极淡的田畴纹理。
> - 省界用点划线；省外区域比省内略暗。
>
> 不要画的内容：不要任何文字、站名、铁路线、道路、城市图标、图例、边框装饰。车站圆点和线路由游戏另外绘制，底图在这些位置要保持安静、低对比。
>
> 色彩：暖米黄为主，水面灰青，山地橄榄绿和赭石，整体低饱和、低对比。

## 验收

- 黄河仍然从 郑州–新乡、郑州–焦作、洛阳–济源、兰考–濮阳 四处线路下面穿过，别处不与线路相交。
- 站名位置上没有深色块或文字。
- 在游戏里桌面和手机宽度各看一遍，线路和站名比底图醒目。
